# 实施任务清单：AI 漫剧制作工作台

Feature Name: ai-comic-drama-studio
Updated: 2026-08-11
默认技术栈：Vue3 + Vite + Pinia / FastAPI + SQLite + FFmpeg / 本地单机部署

## Phase 0: 项目脚手架（2-3 天）

- [x] T0.1 初始化 monorepo 结构：`frontend/`（Vite + Vue3 + TS + Pinia + Vue Router）、`backend/`（FastAPI + SQLAlchemy）
- [x] T0.2 后端基础框架：应用入口、配置管理、异常处理中间件、统一响应格式、OpenAPI schema 生成
- [x] T0.3 SQLite 建库与 Alembic 迁移：按 design.md Data Models 建 9 张表
- [x] T0.4 素材目录结构初始化（`media/{project_id}/{characters|shots|audio|exports}`）
- [x] T0.5 Vite 配置 `/api` 反向代理至后端 8000 端口；allowedHosts 放行 `.monkeycode-ai.online`
- [x] T0.6 前端路由与六步步骤导航框架、全局项目状态管理

## Phase 1: AI Provider 适配层（3-4 天）

- [ ] T1.1 定义 `TextProvider` / `ImageProvider` / `TTSProvider` 抽象接口
- [ ] T1.2 实现 `openai_compatible` 提供商（LLM chat completions + TTS /audio/speech）
- [ ] T1.3 实现图像生成适配：openai 兼容 images + 即梦/可灵厂商 HTTP 适配骨架（可插拔）
- [ ] T1.4 垫图降级机制：不支持参考图的提供商自动降级为纯描述词并标注
- [ ] T1.5 模型配置的连通性测试：`POST /model-config/test`
- [ ] T1.6 API Key 加密存储（Fernet + 本机派生密钥）与导出脱敏

## Phase 2: 项目与剧本模块（3 天）

- [ ] T2.1 项目 CRUD API + 前端项目列表/新建页
- [ ] T2.2 剧本生成 API：题材 → 200-300 字初稿 + 三段结构（开头/冲突/结尾）
- [ ] T2.3 节奏分段：按 15-20 秒输出情绪转折点标记
- [ ] T2.4 剧本改写/重新生成 + 拗口句提示（启发式：超长句与重复词标注）
- [ ] T2.5 角色/场景抽取：从剧本中抽角色名与场景名登记入库
- [ ] T2.6 剧本工坊前端页：编辑器 + 生成结果卡片 + 改写操作

## Phase 3: 分镜模块（3 天）

- [ ] T3.1 剧本 → 分镜拆解 API：20-30 镜头，含景别/台词/情绪
- [ ] T3.2 动作拆分逻辑：识别多阶段动作，拆为连续分镜（抓杯—砸地—碎片）
- [ ] T3.3 景别轮换算法：每 3-5 镜头切换景别/角度
- [ ] T3.4 台词覆盖校验：剧本台词与分镜台词映射无遗漏
- [ ] T3.5 分镜表前端：可编辑表格、拖拽排序、自动重排镜头号、过渡分镜提示
- [ ] T3.6 过渡分镜建议：相邻镜头画面跳跃时提示补镜

## Phase 4: 角色与场景定妆（3 天）

- [ ] T4.1 角色 CRUD + 形象关键词维护
- [ ] T4.2 定妆照生成 API：关键词 → 图像生成 → 保存 `characters/`
- [ ] T4.3 场景描述词登记与复用
- [ ] T4.4 角色/场景库前端页：定妆照展示、关键词管理、垫图入口

## Phase 5: 批量生图（4 天）

- [ ] T5.1 单镜头生图 API：画面描述 + 角色关键词 + 定妆照垫图 + 场景描述词 → 2-3 张候选
- [ ] T5.2 候选择优：候选图入库 `shot_assets`，`is_selected` 选图切换
- [ ] T5.3 风格一致性评分（图像嵌入相似度）辅助择优
- [ ] T5.4 5 镜头试拍与风格校验：对风格偏差过大给出提示
- [ ] T5.5 视角多样性检查：正脸大头照占比过高时提示补充俯拍/仰拍/手部特写
- [ ] T5.6 形变重试：调整描述词/角度一键重新生成
- [ ] T5.7 生图工作台前端：分镜卡片流 + 候选图对比 + 批量操作

## Phase 6: 音频工坊（3 天）

- [ ] T6.1 逐句配音 API：台词 + 情绪 → 独立音频文件；支持音调/语速调整
- [ ] T6.2 BGM 管理：上传/选取，音量默认 -12dB（人声的 20-30%）
- [ ] T6.3 SFX 音效对齐：音效关联镜头号，按时间轴放置
- [ ] T6.4 音频工坊前端：配音列表、情绪配置、音量滑杆、时间轴预览

## Phase 7: 剪辑合成（4 天）

- [ ] T7.1 合成参数校验：镜头时长域 {0.5,1.5,2.0}、素材存在性、音频电平
- [ ] T7.2 FFmpeg 合成管线：图片序列 zoompan 推拉运镜 → 混音（人声+BGM+SFX）→ 字幕烧录 → 1080×1920 H.264 MP4
- [ ] T7.3 合成预览：低分辨率快速合成 + 音画同步检测（音轨 vs 镜头总时长偏差提示）
- [ ] T7.4 导出与半成品清理：导出成功落库 `exports`，失败清理临时文件
- [ ] T7.5 剪辑合成前端：时间轴、时长编辑、运镜开关、导出进度

## Phase 8: 测试与验收（3 天）

- [ ] T8.1 单元测试：剧本校验/分镜拆分/景别轮换/台词覆盖/Key 加解密/provider mock 契约
- [ ] T8.2 集成测试：3 图 + 2 句 TTS → FFmpeg 导出 → 断言分辨率/时长/码率
- [ ] T8.3 前端 OpenAPI 契约测试与类型生成
- [ ] T8.4 六步流程端到端人工验收，对照 requirements.md R1-R9 逐条勾验
- [ ] T8.5 部署脚本：一键启动前端 + 后端 + FFmpeg 自检

## 里程碑

- M1（T0-T2）：项目管理 + 剧本创作跑通
- M2（T3-T4）：分镜 + 定妆跑通
- M3（T5-T6）：生图 + 音频跑通
- M4（T7）：全流程合成导出成片
- M5（T8）：测试验收与部署交付
