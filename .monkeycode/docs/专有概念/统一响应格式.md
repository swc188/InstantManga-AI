# 统一响应格式

统一响应格式是后端所有 HTTP 响应的契约，保证前端能以一致方式解析成功与失败。

## 什么是统一响应格式？

后端（FastAPI）对每个请求返回 `{code, message, data}` 三字段 JSON：

- `code`：0 表示成功，非 0 为错误码（默认与 HTTP 状态码一致）
- `message`：人类可读消息，成功为 `"ok"`
- `data`：业务数据，失败时通常为 `null`

**关键特征**:
- 业务模块返回 `ApiResponse`（`core/response.py`），错误码 0
- 异常经 `core/errors.py` 的处理器统一转换为该格式，包括未捕获异常（500）与校验失败（422）
- 前端 `api/client.ts` 只认该格式：`code !== 0` 抛 `ApiError`，成功返回 `data`

## 代码位置

| 方面 | 位置 |
|------|------|
| 响应模型 | `backend/app/core/response.py` |
| 异常处理 | `backend/app/core/errors.py` |
| 注册 | `backend/app/main.py`（exception_handler） |
| 前端解析 | `frontend/src/api/client.ts` |

## 不变量

1. **格式完整**: 所有响应必须包含 `code`、`message`、`data` 三个字段
2. **成功语义**: `code === 0` 与 HTTP 2xx 同时成立
3. **错误可见性**: 业务异常（ApiError）与框架异常（404/422/500）均输出统一格式
