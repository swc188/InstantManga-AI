# 模型配置

模型配置（ModelConfig）是用户为文本生成、图像生成、语音合成三类能力各自配置的 AI 服务条目。

## 什么是模型配置？

`model_configs` 表保存三类能力的供应商接入参数。设计上每条配置含 `provider_type`（如 `openai_compatible`、`jimeng`、`keling`、`midjourney`）、`base_url`、`model_name` 与加密存储的 `api_key_enc`。`is_valid` 标记连通性校验结果。

**关键特征**:
- 默认服务商：项目默认模型服务 Base URL 为 `https://agnes-ai.cn`（`config.py` 的 `default_model_base_url`，可用 `ACD_DEFAULT_MODEL_BASE_URL` 覆盖）
- 三类能力：`capability` 取值为 `text` / `image` / `tts`，唯一约束，每类一条
- 密钥加密：API Key 以 Fernet 加密存入 `api_key_enc`，导出项目时脱敏（Phase 1 实现）
- 校验：配置保存时触发连通性测试，未通过标记 `is_valid=0` 并禁止使用（Phase 1 实现）

## 代码位置

| 方面 | 位置 |
|------|------|
| 模型 | `backend/app/models/model_config.py` |
| 适配层 | `backend/app/providers/`（Phase 1 实现） |
| 前端 | `frontend/src/views/ModelConfigView.vue`（占位） |

## 不变量

1. **能力唯一**: 同一 `capability` 至多一条配置
2. **密钥保护**: 数据库只存密文，任何 API 响应不返回明文 Key
3. **可用性门控**: `is_valid=0` 的配置对应的 AI 能力不得发起任务
