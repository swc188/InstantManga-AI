# 素材目录

素材目录是按项目组织的本地文件存储结构，承载图片、音频、视频等大文件，元数据则存于 SQLite。

## 什么是素材目录？

所有非结构化文件统一存放在 `backend/media/{project_id}/` 下，按类型分子目录：

```
media/
└── {project_id}/
    ├── characters/    # 角色定妆照
    ├── shots/         # 分镜候选图与正式选图
    ├── audio/         # 配音 / 背景音乐 / 音效
    └── exports/       # 合成成片
```

**关键特征**:
- 动态创建：`ensure_project_media(project_id)` 幂等建立四个子目录
- 相对引用：数据库 `file_path` 字段存相对 `media_root` 的路径，便于整体迁移
- 忽略上传：`.gitignore` 忽略 `backend/media/**`（仅保留 `.gitkeep`）

## 代码位置

| 方面 | 位置 |
|------|------|
| 创建逻辑 | `backend/app/core/storage.py` |
| 根目录配置 | `backend/app/config.py`（`ACD_MEDIA_ROOT`） |

## 不变量

1. **四类固定**: 子目录固定为 `characters|shots|audio|exports`
2. **项目隔离**: 素材不跨 `project_id` 共享
3. **幂等创建**: 重复调用 `ensure_project_media()` 不产生副作用
